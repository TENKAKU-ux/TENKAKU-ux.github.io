ふるさと納税マップ 自治体の収支を地図で見る

ふるさと納税で寄附を集めている自治体がある一方で、住民が他の自治体へ寄附すると、その分だけ住民税が減る自治体もあります。このサイトでは、総務省の「ふるさと納税に関する現況調査結果」をもとに、自治体ごとの受入額と住民税の控除額を並べ、その差額を日本地図の色分けや全国の順位で見られるようにしました。人口1人あたりの額、募集費用の中身、受入額の推移（平成20年度から）も見られ、ページの URL をそのまま共有できます。また、AI エージェントが同じデータを調べられるように、ブラウザ向けの WebMCP と、Claude Code などに登録できる MCP サーバーも用意しています。非公式のサイトで、出典は総務省・e-Stat・国土地理院です。

詰まった点と抜け方

01

都道府県と市区町村の数字をそのまま足すと、住民税の控除額が二重に数えられてしまう。

都道府県と市区町村を別の表に分け、全国の合計と47都道府県の値が総務省の報道資料と一致するかをテストで毎回確かめるようにした。

02

日本地図に離島まで正しい位置で描くと、本土が小さくなって見づらい。距離で自動的に外す方法では、本土の市町村まで外れてしまった。

遠い島だけを名前で指定し、地図の外に名前のボタンとして並べる形にした。

03

地図の元データが2016年のもので、その後に市になった自治体はコードが変わっていて、色が塗られなかった。

変わったコードを読み替える表を作り、すべての自治体に色が付くことを確かめた。
